# You & AI website

Next.js frontend and Vercel contact API. See the [root README](../README.md) for setup, owner inputs, and deployment instructions.

Run `npm install`, `npm run dev`, `npm run lint`, `npm run typecheck`, or `npm run build` from this directory. Public company information is in `src/content/business.json`. Secrets belong in `.env.local` locally and the Vercel environment in production.
